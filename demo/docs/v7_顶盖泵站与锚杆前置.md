## 二、定值与可复算关系

### 1. 标高链（单位：三维单位，1 单位 = 22.17 m）

```
Z_HALF = 3.20252          BOX_Z   = Z_HALF + .47           = 3.67253
SURF_U = 7.04556 (地表局部高) BOX_TOP = SURF_U + YB(Z_HALF) + .06 = 10.80352
                          GLASS_Y = BOX_TOP + .07          = 10.87352   ← 顶盖玻璃上表面
                          PIPE_H_Y= GLASS_Y + .10          = 10.97352   ← 跨顶盖水平管轴高
PUMP_Y = GLASS_Y − 7.12   = 3.75352                                    ← 泵站组 y，橇板底面 7.12 → 玻璃面
ROD_Z  = Z_HALF + .06     = 3.26252      ROD_BASE = YB(Z_HALF) = 3.69796
```

`YB(z) = (z + zHalf) · SLOPE`，`SLOPE = tan30° = 0.57735`（`data/geology.js` 唯一来源）。

### 2. 管路为什么"不断开"

管路全部沿 `z = 1.95` 一条竖直面内走：

| 段 | 起点 → 终点（世界坐标） |
| --- | --- |
| 泵出口短管 | `(−3.82, PUMP_Y+7.42=11.17, .72)` → `(−3.82, PUMP_Y+7.88=11.63, 1.95)` |
| 弯头 | `(−3.82, 11.63, 1.95)` → `(−3.82, PIPE_H_Y=10.97, 1.95)` |
| 跨顶盖水平管 | `(−3.82, 10.97, 1.95)` → `(−.72, 10.97, 1.95)` |
| 竖管（穿岩层） | `(−.72, 10.97, 1.95)` → `(−.72, PL+GRT, 1.95)` |
| 孔口法兰 | 中心 `(−.72, GLASS_Y+.02 = 10.89, 1.95)`，`0.26×0.05×0.26` |

相邻段端点**逐位相同**（同一常量表达式），故无缝隙。竖管下端点：

```
PL   = YB(1.95) = (1.95 + 3.20252) × 0.57735 = 2.97490
GRT  = 4.2534（地层组内离层局部高）
PL+GRT = 7.2283
```

而地层组内 `local y = GRT、z = 1.95` 的点映射到世界为 `GRT + LIFT + SLOPE·1.95 = 4.2534 + 1.84904 + 1.12583 = 7.2283`
——两者相等，说明竖管下端正好落在该 z 处的离层高度上（`inletGroup` 改挂 `strata` 后随地层同步沉降）。

竖管④是唯一"活动"的一段：`updateCase` 里 `end = (GRT+deflect(−.92,6) + GRT+deflect(−.92,5))/2`，
`downPipe.position.y = (PIPE_H_Y + PL+end)/2`、`downPipe.scale.y = (PIPE_H_Y − (PL+end)) / (PIPE_H_Y − (PL+GRT))`，
即圆周向两端对称伸缩，**上端恒为 `PIPE_H_Y`、下端恒为 `PL+end`＝离层内扩散源高度**，
`end` 在 p=0.72 时比静止态低约 0.26 单位，正是靠这一项补偿，而不是靠拉长间隙。

### 3. 原版的两处真实缺陷（本次一并修掉）

1. 原 `surfacePipe` 世界 y 恒为 `PL + 7.88 = 10.855`，而泵出口世界 y = `YB(0)+7.88 = 9.729` → **断 1.13 单位**；
   且原 `cap` 与管路不同轴。
2. 原 `inletGroup` 挂 `world`，世界 y ≈ 4.25，而离层在 `z=−.92` 处的世界高度 ≈ 6.1–7.2 → **管口悬在注入点下方约 2–3 单位**，
   v0.6 截图 `s0_grout72.png` 里那截"悬空橙色管头"就是它。

## 三、可见性核算（先算再做）

- 锚杆直径 `r ≈ .028` 单位 ≈ 0.6 m；在 1440×1000 视口、全景机位下箱体宽约 320 px / 12 单位 ⇒ 1 单位 ≈ 27 px，
  杆径约 1.5 px —— **线宽级但长度 190 px**，属"细线可见"，成立的前提是**不被岩体遮挡**：原 `z=1.81` 在岩体内部，
  必然被完全遮挡；移到 `z=3.2625`（前剖切面外 6 cm）后与岩层无交叠，全高可见。
- 泵站整体宽约 2.25 单位 ≈ 60 px，橇板-玻璃面接触线在特写下清晰；顶盖玻璃若不透明度取侧玻璃的 0.085，
  在浅色背景下与背景同值、读不出"玻璃面"，故单列 `glassTop: 0.16`。
- 标签宽 190–330 px：原名 `监测锚杆 · 煤顶至地表全程`（330 px）与 `注浆钻孔 · 孔口在顶盖玻璃上`（430 px）在全景里
  压住锚杆与竖管，故缩短为 `监测锚杆 · 煤顶→地表`／`注浆钻孔 · 孔口在顶盖`。

## 四、已知限制（如实写）

1. 锚杆位于前缘 `+z` 外表面，"背面"机位看的是 `−z` 面，**确实看不到**；该机位不显示锚杆标签（不做指向不可见物的标注）。
2. "注浆"机位（06/07 阶段）是岩体内部特写，泵站与顶盖在画框外——与 v0.6 相同，未改变该机位构图。
3. 泵站被抬到展框顶盖，管口自"玻璃面"向下接入岩层，这是**展示性布置**，不是现场注浆孔的标高关系；页面说明与本文均已标注。
4. 浏览器中 `window.__VERIFY__` / `window.__VERIFY_S1__` 在 v06、v07 均为 `null`（`typeof null === 'object'` 曾骗过探针的重试判断），
   属既有工具链缺陷；本次不据此声明断言通过，S1 侧改用 `__TWINS__` 包围盒比对。
