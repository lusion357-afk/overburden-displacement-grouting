## 1. 一句话结论

v0.9 的三机是「跨厚度示意」：设备被放大到 y≈0.43 单位（≈9.5 m，穿出 6.2 m 煤顶），
**比例不成立**，只为「看得见」。v1.0 把它们按真实米尺寸重建（1:200，与几何相似比一致），
因此**在 3D 全景里必然看不见**（设备总高 3.0 m = 0.135 单位，仅煤厚的 48%，且埋在煤层内部）。
可见性改由两件事承担：新增的 **「三机」机位**（隐藏岩层与采动煤，只留设备 + 底板 + 三角底煤），
以及 3D 视口下方的 **倾向剖面**（等比 17.7 px/m，支架 3.0 m ≈ 53 px、溜槽宽 13.45 px、溜槽高 5.3 px）。

**没有靠放大设备换可见性**——这是本版与 v0.9 的根本区别。

## 3. 布置规则

### 3.1 走向站位（煤壁 x = 0，采空区侧为负）

| 设备 | 中心 x | 说明 |
|---|---|---|
| 采煤机 | −0.9 m | 机身宽 2.0 m，骑在输送机上、贴煤壁 |
| 刮板输送机 | −0.55 m | 槽宽 0.76 m，贴煤壁侧底板 |
| 液压支架 | −3.5 m | 架长 5.0 m，前端 −1.0 m（距煤壁 1.0 m，作业空间），后端 −6.0 m（伸入采空区侧底座） |

三机**同属 `strata` 组**，继承 30° 倾向剪切矩阵（`yW = yLocal + SLOPE·z + LIFT`），
因此「沿煤层底板」= 设备局部 y=0 即煤底，不需要额外旋转——**用剪切而非旋转**，
机身为平行六面体、底座贴底板，与 v0.1 的历史口径一致（`mining-volume.js` 顶部注释）。

### 3.2 倾向（z）铺满

工作面净宽 `Z_WORK0 = zLaneIn1 = −2.99955` → `Z_WORK1 = zLaneRet0 = +2.99955`（133 m）。

- **刮板输送机 88 节**：`panNRamp = 12`（三角煤斜边段）+ `panNFlat = 76`（水平段）= 88，
  88 × 1.5 = 132 m，两端各余约 0.5 m。斜边段 `zc = Z_SLOPE0 + (j+0.5)·1.5`、`d = 1.5/cos(12.53°)`；
  水平段 `zc = Z_FLARE + (j+0.5)·1.5`，`Z_FLARE = rampZ1 = −2.18766`（三角煤尖灭点）。
- **液压支架 88 架**：`supN = floor((Z_WORK1 − Z_SLOPE0)/1.5) = 88`，与溜槽**一板一架**：12 架沿三角煤斜边、76 架水平。
  斜边段支架**底座贴斜面、整架随坡倾斜 12.53°**（与溜槽同一斜边），即「三角底煤的斜边就是这一段的煤层底板」。
  **端头破顶**：斜边最高处（进风端）顶梁 = 4.0 + 3.0·cos(12.53°) ≈ 6.93 m，高出煤顶 6.2 m 约 **0.73 m**。
  这不是建模错误，而是错层位端头的既有工艺——顶梁顶在直接顶上、顶板随采随落【文献：王志强 2013 :846-849 / 2014 图3 / 2024 §3.1】；
  本图未画破顶过程与垮落矸石，属【设定】简化。
- **采煤机 1 台**：`shZ = 0`（倾向中部，lift = 0），沿走向随机身前进，不复制。

### 3.3 抬升曲线（贴三角底煤）

```
lift(z) = z ≤ Z_SLOPE0        → RAMP_RISE = 4.0 m    （进风端头，三角煤满厚）
        = z ≥ Z_FLARE         → 0                    （尖灭点之后，落到煤底）
        = 其间                 → 4.0 · (1 − (z − Z_SLOPE0)/18)
```

- 溜槽每节按 `base = lift(zc)` 抬升，斜边段再叠 `12.53°` 倾角（`d` 加长，保证节间相切）；
- 支架从 `Z_FLARE` 起 `lift = 0`，直接坐煤底；
- 采煤机在 z=0，`lift = 0`。

**这就是「贴着三角底煤的曲线安置」**：4.0 m 平段（4.5 m 巷宽）→ 12 节逐节下落（12.53° 斜边 18 m）→ 落到煤底。

## 4. 可见性核算（1440×1000 视口，箱体 x 向 12 单位 ≈ 1100 px → ≈ 91.7 px/单位）

| 对象 | 真实尺寸 | 3D 像素 | 判定 |
|---|---|---|---|
| 液压支架（宽 1.5 × 高 3.0 m） | 0.068 × 0.135 单位 | ≈ 6.2 × 12.4 px | 可辨（列 + 顶梁轮廓） |
| 刮板输送机（宽 0.76 m） | 0.034 单位 | ≈ 3.1 px | 勉强可辨 |
| 刮板输送机（高 0.30 m） | 0.0135 单位 | ≈ 1.2 px | **不可辨**（< 2 px 阈值） |
| 采煤机（长 8.0 × 高 1.5 m） | 0.36 × 0.068 单位 | ≈ 33 × 6.2 px | 可辨（轮廓） |
| 滚筒（Φ1.8 m） | 0.081 单位 | ≈ 7.4 px | 可辨（在「三机」机位拉近后更大） |

**结论**：
- 3D 全景/开采机位：三机埋在煤内，**看不到是等比例的物理必然**，不得靠放大解决；
- 「三机」机位（`equip`）：相机贴近到约 5 单位、fov 26°，设备列占画面中部，可辨形态与「铺满 + 抬升」；
- 溜槽高位细节（0.30 m 高、逐节 12.53°）：**交由 2D 倾向剖面**（17.7 px/m，槽高 5.31 px、槽宽 13.45 px、
  支架高 53.10 px），并在剖面图例与 note 里写明。

## 7. 未做 / 局限（不得越界表述）

1. **未做实体试验、无现场实测**：三机尺寸是按文献与常规装备量级取的【设定】，不是 1411 工作面的实测配置；
   若后续拿到该面设备清单（支架型号、中心距、采煤机型号），应回填 `EQUIP` 并重跑 E1–E19。
2. **顶上 3.2 m 顶煤的放煤过程未建模**：支架只表达机采 3.0 m 支撑高度，放煤口、后部输送机、端头支架均未画。
3. **端头破顶只做了几何表达**：斜边最上 2 架顶梁高出煤顶 0.73 m，对应端头破顶工艺；破顶过程、垮落矸石、
   端头过渡支架的真实型号（一般为矮架）均**未建模**，属【设定】简化。
4. **「三机」机位隐藏了岩层与采动煤**：这是展示选择，caption 已注明；不要把它当作「工作面里真的没有煤」。
5. 3D 中溜槽高仅约 1.2 px，**截面与逐节抬溜不可辨**，以 2D 剖面为准；这一归属写在页面 note 与诊断 `warns` 里。
